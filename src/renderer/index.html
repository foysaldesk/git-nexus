About Git Nexus

Graphical Git Repository Manager & Integrated Terminal

Git Nexus v1.0.2

A modern, high-performance Graphical Git Repository Manager and Terminal Desktop Application built with Electron, Node.js, and xterm.js.

Electron v34.5
Node.js v20+
xterm.js v5.5
Simple-Git v3.27
Platform macOS

Key Features & Capabilities

📂
Repository Explorer

Browse, switch, and initialize Git repositories instantly.

🌿
Branch & Tag Manager

Create, switch, merge, and delete local and remote branches.

📝
Visual Staging & Diff

Interactive chunk diffs, line numbers, and stage/unstage controls.

📜
Commit & File History

GitHub-style commit timeline and file revision history tracker.

💻
Integrated Terminal

Full xterm.js terminal emulator with multi-tab support.

🖱️
Context Menu Integration

macOS Finder Quick Actions & Windows Explorer context menu ("Open in Git Nexus Terminal").

System Context Menu Integration

Add "Open in Git Nexus Terminal" to your macOS Finder Quick Actions or Windows context menu.
